# Chhatu Kumar - Personal Portfolio

## About the Project

This is my personal portfolio website, created to showcase my skills, projects, education, and internship experience as a Computer Science and Engineering student and aspiring Full Stack Developer.

## Features

- Responsive portfolio design
- Home and About sections
- Technical Skills section
- Projects with GitHub repository links
- Education and Experience timeline
- Contact form with basic validation
- Mobile navigation menu
- Automatically updated copyright year
- Profile photo section
- GitHub and LinkedIn profile links

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

## Projects Showcased

1. **QR Code Generator** — Generates QR codes using HTML, CSS, and JavaScript.
2. **Countdown Timer** — Timer project with day, hour, minute, and second controls.
3. **To-Do List** — A simple task management interface.

## How to Run the Project

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `script.js`, and `Chhatu.jpeg` in the same folder.
3. Open `index.html` in your browser.
